## Reporting a Vulnerability

We take the security of Vexo API seriously. If you discover a security vulnerability, we would appreciate it if you could report it to us confidentially. 

Please **DO NOT** create a public issue for security vulnerabilities. Instead, please reach out to the project owner directly.

We will review your report and respond as quickly as possible. Once the vulnerability has been patched, we will publicly acknowledge your contribution to the project's security.
