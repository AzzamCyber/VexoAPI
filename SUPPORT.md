# 🆘 Get Support

Butuh bantuan dengan Vexo API? Berikut adalah cara mendapatkan bantuan:

## 🔍 Cek Dokumentasi
Sebelum bertanya, harap baca [README.md](README.md) dan [ROADMAP.md](ROADMAP.md) untuk informasi dasar dan rencana proyek.

## 🐛 Laporkan Masalah
Jika Anda menemukan bug pada layanan API kami, silakan buka [Issue baru](https://github.com/AzzamCyber/VexoAPI/issues/new/choose) menggunakan template **Bug Report**.

## 💡 Usulkan Fitur
Punya ide keren untuk Vexo API? Gunakan template **Feature Request** pada bagian *Issues*.

## 💬 Hubungi Developer
Untuk pertanyaan mendesak atau kerjasama bisnis, Anda dapat menghubungi **Azzam Codex** melalui:
- **GitHub**: [@AzzamCyber](https://github.com/AzzamCyber)
- **Website**: [vexoapi.azzamcodex.site](https://vexoapi.azzamcodex.site/)
